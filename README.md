# 국제비교한국학회 홈페이지 운영 매뉴얼

이 저장소가 곧 학회 홈페이지입니다. 여기서 파일을 수정하면 1~2분 안에 사이트에 반영됩니다.

## 딱 하나만 기억하세요

**HTML 파일은 절대 수정하지 않습니다.** 내용 수정은 전부 아래 4개 목록 파일에서만 합니다.

| 파일 | 내용 | 반영되는 곳 |
|---|---|---|
| `conferences.txt` | 학술대회 목록 | 학술대회 캐러셀, 메인 최신 4개 |
| `issues.txt` | 학술지 발간 호 | 학술지 페이지, 메인 최신 4개 |
| `notices.txt` | 공지사항 | 학회소식 페이지 |
| `history.txt` | 연혁 | 학회소개 연혁 표 |

## 공통 수정 방법

1. 위 파일 목록에서 수정할 파일 이름 클릭
2. 오른쪽 위 **연필 아이콘**(Edit this file) 클릭
3. 내용 수정 (규칙은 각 파일 맨 위 `#` 줄에 적혀 있음)
4. 오른쪽 위 초록색 **Commit changes** 버튼 클릭 → 작은 창이 하나 뜹니다. 이 창은 "무엇을 수정했는지" 메모를 남기는 확인 창인데, 아무것도 안 적어도 됩니다. 창 안의 초록색 **Commit changes** 버튼을 한 번 더 눌러야 저장이 완료됩니다
5. 1~2분 뒤 사이트 새로고침으로 확인

- 각 줄은 `내용 | 내용 | 내용` 처럼 세로줄(|)로 칸을 나눕니다.
- `#`으로 시작하는 줄은 화면에 안 나오는 메모입니다.
- **줄 순서가 화면 순서입니다.** 새 항목은 맨 위에 씁니다 (연혁만 예외: 시간순이므로 맨 아래).
- 한 줄이 이상해도 그 줄만 안 보일 뿐 사이트는 정상 작동합니다.

## 시나리오별 안내

### 새 학술대회 올리기
1. 포스터 이미지를 `poster-회차.jpg` 이름으로 준비 (예: `poster-52.jpg`, JPG 형식, 가로 900px 정도 권장)
2. `conference` 폴더 클릭 → **Add file → Upload files** → 포스터 드래그 → Commit
3. `conferences.txt` 맨 위(# 줄들 아래)에 한 줄 추가:
   `52 | 대회 제목 | 2027. 1. 15.(금) · 장소`
4. 대회 개최가 확정 공지 사항이면 `notices.txt`에도 한 줄, 대회가 끝났으면 `history.txt` 맨 아래에도 한 줄 추가

### 학술지 새 호 올리기
- **전자책(현재 방식)**: `issues.txt` 맨 위에 한 줄 —
  `34-3 | 2026. 12. 31. | https://www.kstudy.com/fbook/iacks/34-3/`
- `history.txt` 맨 아래에도 발간 사실 한 줄 추가
- (과거처럼 PDF로 올릴 경우: `journal` 폴더에 `cks-권-호.pdf` 업로드 후 링크 자리에 `journal/cks-권-호.pdf`)

### 공지 쓰기 / 투고 마감 연장하기
- 새 공지: `notices.txt` 맨 위에 `날짜 | 제목 | 내용` 한 줄. 맨 뒤에 `| 링크주소`를 붙이면(선택) 공지에 "바로가기" 링크가 생깁니다
- **마감 연장**: 새 공지를 또 쓰지 말고, 기존 공지 줄에서 날짜와 마감일만 고치고 제목 앞에 `[연장]`을 붙이면 됩니다

### 실수했을 때 (되돌리기)
파일 화면에서 **History** 클릭 → 이전 버전 선택 → 내용 복사해서 다시 붙여넣고 Commit.
모든 수정 기록이 영구 보관되므로 무엇도 잃어버릴 수 없습니다.

## 하지 말아야 할 것

- HTML 파일(.html) 수정 ✕ — 화면이 깨질 수 있습니다. 디자인 수정은 총무이사에게.
- 파일 삭제 ✕ — 필요하면 총무이사와 상의.
- **`CNAME` 파일은 절대 수정·삭제 금지** ✕ — 학회 주소(iacks.org) 연결 정보입니다. 지워지면 사이트 주소가 끊깁니다.
- 큰 파일(25MB 초과)을 Upload files로 올리기 ✕ — 실패합니다. 대용량은 Releases 기능 사용 (총무이사에게 문의).
